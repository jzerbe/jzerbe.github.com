# Jason Zerbe's profile page
<https://jzerbe.com>

This site is automatically generated by [Jekyll](http://github.com/mojombo/jekyll)
when the repository is pushed to GitHub.

## Writing a post
Each post is an experiment: the problem, what I tried, and whether it worked. Lead with a `__Result:__` line.

Optional front matter:
- `outcome`: `WORKED`, `MIXED`, `FAILED`, `ONGOING`, or `UNTESTED` (researched, not tried yet). Shows as a badge on the post and the homepage.
- `location`: `lat, long` shown in the post header. No default: leave it off and the row is hidden.

## Development
1. `sudo apt install build-essential ruby ruby-bundler ruby-dev ruby-full rubygems`
1. `bundle install`
1. `bundle exec jekyll serve`
